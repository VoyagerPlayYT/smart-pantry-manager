Интеллектуальная система домашнего учёта продуктов и контроля сроков годности: зонирование запасов (холодильник, морозилка, сухой склад/кладовая, специи), трёхцветная шкала свежести (свежее / истекает через 3 дня / просрочено), автоматическая генерация семейного списка покупок и рекомендательный движок «Что приготовить прямо сейчас?» на основе доступных остатков.

## Инженерные особенности

- **Динамический расчёт сроков годности:** SQLite даты и автоматическое вычисление оставшихся дней относительно текущего времени.
- **Зонирование хранения:** Мгновенный фильтр по отсекам (Холодильник, Морозильная камера, Кладовая, Специи).
- **Синхронизация списка покупок в 1 клик:** Алгоритмический перенос всех позиций, срок годности которых истекает в течение 3 дней, в общий список покупок для супермаркета.
- **Рекомендательный движок рецептов:** Сравнение доступных в кладовой ингредиентов со справочником домашних блюд (плов, карбонара, сырники, омлеты) с расчётом процента готовности и списком недостающих компонентов.

## Зачем этому проекту нужен выделенный домашний сервер 24/7 (HP ProLiant DL360 Gen9)

1. **Непрерывный семейный доступ на кухне 24/7:** HP ProLiant DL360 Gen9 работает круглосуточно, позволяя открывать список продуктов и рецепты с кухонного планшета, умного холодильника или телефонов членов семьи прямо во время готовки.
2. **Нулевой риск порчи продуктов и экономия бюджета:** Сервер ежедневно проверяет базу данных и заблаговременно предупреждает о продуктах с истекающим сроком годности, предотвращая выбрасывание еды.
3. **Локальная база данных без абонентской платы:** В отличие от платных облачных приложений для учёта продуктов, все списки покупок и рецепты хранятся на локальном отказоустойчивом дисковом пуле сервера.
4. **Интеграция с локальной сетью:** Быстрая загрузка на скорости локальной сети с нулевой задержкой.

## Запуск в 1 клик

```cmd
start.bat
```
Скрипт проверит зависимости и запустит Smart Pantry Manager на `http://localhost:8019`.
